# Rogue Trader Bestiary Reference
## Optimized for AI consumption — creature stat blocks for game implementation

---

## Stat Block Format

```
Name
WS  BS  S   T   Ag  Int Per WP  Fel
XX  XX  XX  XX  XX  XX  XX  XX  XX
Movement: Half/Full/Charge/Run    Wounds: XX
Armour: Description (Locations AP)    Total TB: X
Skills: ...
Talents: ...
Traits: ...
Weapons: Name (Damage Type; Pen X; Qualities)
```

### Key:
- (X) after S/T/Ag = Unnatural multiplier (e.g., S(10) with Unnatural Strength ×2 means SB=10)
- Movement: Half/Full/Charge/Run in metres
- TB = Toughness Bonus (including Unnatural multipliers)

## Creature Traits Reference (Game-Relevant)

| Trait | Effect |
|---|---|
| Bestial | Cannot be reasoned with; immune to Fear, Pinning, Intimidation, social skills |
| Brutal Charge | +3 damage on Charge attacks |
| Daemonic(X) | Ignore first X damage per hit (like extra TB); immune to disease, poison |
| Dark-Sight | See in complete darkness |
| Fear(X) | Enemies must pass WP test or suffer penalties (1=normal, 2=-10, 3=-20, 4=-30) |
| Flyer(X) | Can fly; X = movement in metres |
| From Beyond | Immune to Fear, Pinning, Insanity, mind-affecting effects |
| Improved Natural Weapons | Natural weapons are no longer Primitive |
| Multiple Arms | Extra attacks or extra actions with additional limbs |
| Natural Armour(X) | AP X on all locations |
| Natural Weapons | Can make melee attacks dealing 1d10+SB damage |
| Regeneration(X) | Recovers X Wounds at start of each turn |
| Size(X) | Affects hit modifiers and wound threshold |
| Sturdy | Cannot be knocked down |
| Toxic | Target must pass Toughness test or take extra 1d10 damage (ignores armour) |
| Unnatural Characteristic(×X) | Characteristic Bonus is multiplied by X |
| Warp Instability | Takes damage when failing WP tests far from Warp |

### Size Categories
| Size | Modifier to Hit | Stealth Mod | Example |
|---|---|---|---|
| Puny | -30 | +30 | Insect |
| Scrawny | -10 | +10 | Bird, small animal |
| Average | +0 | +0 | Human |
| Hulking | +10 | -10 | Ork, Ogryn |
| Enormous | +20 | -20 | Vehicle-sized |
| Massive | +30 | -30 | Titan, Void Kraken |
