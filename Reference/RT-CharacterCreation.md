# Rogue Trader Character Creation Reference
## Optimized for AI consumption — character generation rules

---

## 1. Characteristic Generation

### Standard Method (2d10 + 25)
Roll 2d10 + 25 for each of the 9 core characteristics:
- WS, BS, S, T, Ag, Int, Per, WP, Fel
- Range: 27-45 (bell curve centered on 35)
- Players may re-arrange or swap two characteristics

### Alternative: Point-Buy
- Start all characteristics at 25
- Distribute 100 points across 9 characteristics
- Maximum single characteristic: 40 at creation
- Minimum single characteristic: 20 at creation

### Home World Modifiers
| Home World | Bonuses | Penalties |
|---|---|---|
| Feral World | +5 S, +5 T | -5 Int, -5 Fel |
| Forge World | +5 Int, +5 WP | -5 Fel, -5 Ag |
| Hive World | +5 Ag, +5 Per | -5 T, -5 WP |
| Imperial World | +5 WP, +5 Fel | -5 Per, -5 Ag |
| Noble Born | +5 Fel, +5 Int | -5 T, -5 Ag |
| Void Born | +5 WP, +5 Int | -5 S, -5 Fel |
| Death World | +5 Ag, +5 T | -5 Int, -5 Fel |

## 3. Wounds

### Wound Calculation
- Base Wounds = 1d5 + Career Modifier + Toughness Bonus
- Career Modifiers: Arch-Militant +5, Rogue Trader +3, others +1 to +3
- Typical starting range: 10-18

### NPC Wound Scaling
| NPC Tier | Typical Wounds |
|---|---|
| Minion/Troop | 6-10 |
| Standard | 10-15 |
| Elite | 15-25 |
| Master | 25-40 |
| Monster/Boss | 40-100+ |

## 6. Fate Points

- Starting Fate: 1d5 (modified by home world)
- Spending: Re-roll a failed test, gain +10 to a test, recover from a mortal wound
- Burning (permanent loss): Avoid certain death
- Typical starting range: 2-4

---

## 7. Profit Factor (Rogue Trader specific)

- Starting PF: Determined by dynasty creation (typically 40-60)
- Used for: Acquiring equipment, services, ships, crew
- Acquisition Test: d100 ≤ PF + modifiers - item rarity penalty
- PF increases from successful Endeavours
- PF decreases from major losses or expenditures
